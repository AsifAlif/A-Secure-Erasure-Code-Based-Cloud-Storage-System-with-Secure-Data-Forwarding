# A Secure Erasure Code-Based Cloud Storage System with Secure Data Forwarding

My final-year undergraduate project. The system combines **primary encryption**, **erasure coding**, **threshold proxy re-encryption**, and **secure data forwarding** to provide confidential, robust, distributed cloud storage: data is encrypted, split into fragments, re-encrypted, and distributed across independent servers, so that compromising any single server does not reveal the original data.
